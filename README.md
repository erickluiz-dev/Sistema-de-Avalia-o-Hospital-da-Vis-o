# Sistema de Avaliação — Hospital da Visão

Sistema web para registro e análise de avaliações de satisfação dos pacientes e avaliação dos funcinarios do Hospital da Visão.

## Tecnologias

### Backend
- Go
- net/http
- PostgreSQL
- pgx/v5

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- Recharts
