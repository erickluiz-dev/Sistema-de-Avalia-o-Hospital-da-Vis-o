# Frontend — Sistema de Avaliação Hospital da Visão

Frontend do sistema de avaliação de satisfação de pacientes do Hospital da Visão.

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- Recharts
- Lucide React
- vite-plugin-pwa
- pnpm
